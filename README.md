# 微信小程序 - 公司信息页面

## 项目说明

这是一个完整的微信小程序公司信息展示页面，包含以下功能：

- 🎨 轮播图展示
- 📝 公司简介和统计数据
- 👥 核心团队成员展示
- 📍 公司及分公司位置信息
- 📱 响应式设计，适配各种屏幕

## 文件结构

\`\`\`
├── pages/
│   └── company/
│       ├── company.wxml    # 页面结构
│       ├── company.wxss    # 页面样式
│       ├── company.js      # 页面逻辑
│       └── company.json    # 页面配置
├── images/                 # 图片资源目录（需自行添加）
├── app.json               # 小程序全局配置
└── sitemap.json           # 搜索配置
\`\`\`

## 使用方法

1. **下载代码**
   - 点击右上角三个点，选择"Download ZIP"下载代码

2. **导入微信开发者工具**
   - 打开微信开发者工具
   - 选择"导入项目"
   - 选择下载的项目文件夹
   - 填写 AppID（测试可使用测试号）

3. **添加图片资源**
   在项目根目录创建 `images` 文件夹，添加以下图片：
   - carousel-1.jpg, carousel-2.jpg, carousel-3.jpg（轮播图）
   - avatar-1.jpg 到 avatar-6.jpg（团队成员头像）
   - share-cover.jpg（分享封面图）

4. **自定义内容**
   在 `company.js` 的 `data` 中修改：
   - 公司简介文字
   - 团队成员信息
   - 公司位置信息
   - 统计数据

## 功能特点

- ✅ 自动轮播，支持循环播放
- ✅ 渐变色卡片设计
- ✅ 圆角头像展示
- ✅ 总部标识徽章
- ✅ 支持分享功能
- ✅ 响应式布局

## 技术栈

- 微信小程序原生开发
- WXML + WXSS + JavaScript
- Grid 和 Flexbox 布局

## 注意事项

1. 图片路径需要根据实际项目调整
2. 可以将图片上传到云存储，使用 HTTPS 链接
3. 建议图片尺寸：轮播图 750x500px，头像 200x200px
4. 测试时可以使用占位图片
